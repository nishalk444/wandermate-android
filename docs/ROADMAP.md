# Production expansion

The current release delivers a guest-first, device-local travel companion. These are explicit future integrations, not enabled features hidden behind placeholder controls.

1. **Verified global catalog**: choose a places/content provider, maintain freshness timestamps, licensed photos, actual addresses, structured opening hours and accessible-facility data. Add editorial review and locale/currency support.
2. **Real routing**: embedded map provider and route-time API, transport-mode choice, reservations and opening-hour constraints. Current distances are straight-line only.
3. **Cloud collaboration**: backend choice, account and guest migration, per-trip member permissions, invitation delivery, conflict resolution, offline sync and deletion/export policy. Do not ship open development security rules.
4. **Commercial weather**: choose an appropriate service plan and secure credential handling for launch; refresh and cache based on provider terms.
5. **Release hardening**: current Play target requirements, release signing, migration tests, process-death tests, full accessibility audit, tablet/adaptive layout work and localization. CI currently builds debug APKs only.
6. **Sensitive-document controls**: app-owned encrypted ticket storage and optional biometric unlock if storing private documents becomes a product requirement. Current attachments reference the document provider.
